# SID Warrant Registration App

A web application that reads SID meeting minutes PDFs, extracts warrant data using Claude AI, and generates formatted Excel registration files.

---

## Running Locally

### Setup (one time)
```
pip install flask openpyxl python-dotenv gunicorn
```

Add your API key and password to the `.env` file:
```
ANTHROPIC_API_KEY=sk-ant-xxxxxxxxxxxxxxxx
APP_PASSWORD=your-chosen-password
SECRET_KEY=any-random-string
```

### Run
```
python app.py
```
Open **http://localhost:5000**

---

## Deploying to Railway (cloud hosting)

Railway hosts the app so anyone can access it from any browser, anywhere.

### One-time setup

**1. Create accounts**
- GitHub: github.com (free)
- Railway: railway.app (free tier available)

**2. Put the app on GitHub**
- Download GitHub Desktop from desktop.github.com
- Create a new repository called `warrant-app`
- Drag the `warrant_app` folder contents into it
- Click "Commit to main" then "Push origin"
- Make sure `.env` is NOT included (the `.gitignore` file handles this)

**3. Deploy on Railway**
- Go to railway.app → New Project → Deploy from GitHub repo
- Select your `warrant-app` repository
- Railway will detect it is a Python app automatically

**4. Set environment variables on Railway**
In your Railway project, go to the Variables tab and add:
```
ANTHROPIC_API_KEY    =  sk-ant-xxxxxxxxxxxxxxxx
APP_PASSWORD         =  your-chosen-password
SECRET_KEY           =  any-long-random-string
```

**5. Get your URL**
Railway gives you a public URL like `warrant-app-production.up.railway.app`
Share this with your team - they open it in any browser and enter the password.

### Updating the app
When you get updated files from Claude:
- Replace the files in your local folder
- In GitHub Desktop: commit the changes and push
- Railway automatically redeploys within about 2 minutes

- Sarpy and Douglas County formats handled automatically
- VOID warrants excluded from registration sheet
- General Fund: 3-year maturity | Construction Fund: 5-year maturity
